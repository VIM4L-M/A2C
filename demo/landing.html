BUILT AROUND YOUR CHOICES

Permission isn't a checkbox
you forget about.

Local by default

Standard facts stay in browser storage. Private facts use an encrypted vault. Standard browser storage itself is not encrypted.

Specific to the site

Allow once, remember an origin and category, or deny. Review and revoke permissions whenever you need.

Some fields stay yours

Passwords, one-time codes and security credentials stay manual. AI suggestions cannot override these rules.

AI mapping sends field labels and memory key names, not saved values. Draft generation shares only facts you explicitly select. Backboard cloud memory is a separate opt-in.

Download source ZIP ↓Setup instructions ↗
Install the developer build
  1. Download and extract the repository.
  2. Run npm ci and npm run build.
  3. Open chrome://extensions, enable Developer mode and choose Load unpacked.
  4. Select apps/extension/dist, then open A2C from Chrome's extension menu.
  5. For local AI, start Ollama and the A2C backend, then test the connection in Settings.

Source downloads reflect published main. Uncommitted local improvements are not included until approved and pushed.
